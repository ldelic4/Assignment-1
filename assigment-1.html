About this project

Bay & Bloom is a fictional Tampa Bay fashion boutique. The site is a static prototype of a back-office tool that would later be connected to a real database: an owner can manage inventory and review sales trends from one place.

All product and sales figures are sample data created for this assignment.

How I built it

I started by sketching the four pages and a single navigation menu so every page feels like part of the same site. I then built one shared stylesheet with a small color palette (dusty rose, sage and warm neutrals) to give the boutique a consistent, professional look.

The product and sales data live in one JavaScript file (js/data.js), so the home page, inventory page and analytics page all read from the same source, the way a real data-driven site would read from a database. The Manage Inventory page mocks the four CRUD operations with a form and table, and saves changes in the browser so they carry over to the analytics charts.

To keep the site fast, I avoided large images and heavy frameworks: the visuals are CSS gradients and emoji icons, and the only external library is Chart.js, which loads on the analytics page alone. The layout uses CSS Grid and Flexbox so it adapts from phone to desktop, and the menu collapses into a toggle button on small screens.

The biggest lesson for me was how much small details, like highlighting the current page in the menu, flagging low stock in red, and confirming before a delete, affect how easy a site is to use.
