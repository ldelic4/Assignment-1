# Bay & Bloom Boutique — ISM 6225 Assignment 1 (Look and Feel)

Static prototype of a data-driven website for a fashion boutique.

| Page | File | Purpose |
|---|---|---|
| Home | `index.html` | Overview of the boutique, categories, new arrivals |
| Manage Inventory | `inventory.html` | Mock CRUD form and table for products |
| Analytics | `analytics.html` | Chart.js visualizations of sales and stock |
| About Us | `aboutus.html` | Student developer profile and build notes |

Shared files: `css/main.css`, `js/main.js` (menu), `js/data.js` (sample data), `js/inventory.js`, `js/analytics.js`.

All data is sample data for demonstration.
